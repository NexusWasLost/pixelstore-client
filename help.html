What this is ?

Pixel Store is a mini marketplace created as a demo project showcasing a full Razorpay integration. It features a product catalog, persistent cart, secure checkout, payment verification and automatic invoice generation, built end to end.

How to use

Using Pixel Store is extremely easy and straightforward:

1. Browse the catalog, add products to your cart.
2. Hit the cart icon on the top to view your cart and then hit checkout to go to the checkout page.
3. Fill in your name as the name of order and email address then hit "Pay Now", and complete the payment on the Razorpay checkout window. On success, you'll be redirected to a confirmation page with an invoice download.

Payment methods

Payments are processed through Razorpay's checkout. Since this is a demo project, UPI is not available as a payment method, but the payment methods below can be used:

Wallets

Wallets are one of the easiest ways to pay, and since this is a demo project it doesn't require any real account at all.

To use wallets, select the "Wallet" option and go with any wallet of your choice.

The list of available wallets can be found below:

Wallet Name Requires credentials
Airtel Payments Wallets No
Ola Money No
Mobikwik Wallet Yes (Email address)

Netbanking

Similar to wallets, the netbanking method is also very straightforward to use and doesn't require a real bank account.

To use netbanking, select the "Netbanking" option and go with any bank of your choice.

Cards

For using cards, Razorpay provides dummy card numbers that you can use.

To use cards, select the "Cards" option and enter any of the card numbers given below. For the expiry field, use any future date from today in MM/YY format, and for CVV any random 3-digit number will work. Lastly, after entering the card details, a prompt to enter an OTP will appear, where any number can be used as the dummy OTP.

The list of available dummy card numbers can be found below:

Network Card Number
Visa 4100 2800 0000 1007
RuPay 6527 6589 0000 1005
Mastercard 5555 5100 0008 1006
Diners 3608 280009 1007

View Razorpay's docs for the full list of cards and other details here.

Finally, since this is a sandbox payment setup the user (you) have full control over if the payment succeeds or fails. To complete the transaction you need to hit the "Success" button to make the transaction success and "Failure" if you wish fail the transaction.

Other info

This project runs against Razorpay's test mode, so no real money is involved. The checkout uses Razorpay's sandbox environment, where you can manually choose Success or Failure on the mock bank page. Since this is a demo, no real card or bank details should be entered ! Use Razorpay's published test credentials.
